# Coach — Question Toolkit

Use these patterns, adapted to the user's words:

| Purpose | Question |
|---|---|
| Clarify the goal | "If this went perfectly, what would be different in three months?" |
| Find the real problem | "What makes this hard *now*, when it wasn't before?" |
| Surface assumptions | "What would have to be true for that to work?" |
| Test with evidence | "What's the cheapest way to find out if that's true?" |
| Change perspective | "What would you advise a friend in exactly this situation?" |
| Find leverage | "Which one decision would make the other decisions easier?" |
| Commit | "What's the smallest step you'll take before tomorrow evening?" |

Avoid "why" questions that sound like accusations; prefer "what" and "how".
